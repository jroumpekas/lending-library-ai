
# Lending Library AI - Recommendation Microservice

AI-powered recommendation microservice built with **FastAPI**, designed to integrate seamlessly with a Spring Boot backend and a React frontend as part of a microservices architecture.

## 🚀 Technologies Used

* **Python**
* **FastAPI**
* **Uvicorn** (ASGI Server)
* **Pydantic** (Data validation)

## 📁 Project Structure

```text
lending-library-ai/
├── main.py          # FastAPI application & endpoints
├── requirements.txt # Project dependencies
└── .gitignore       # Git exclusion rules
```
